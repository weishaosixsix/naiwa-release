# scripts 目录说明

内置脚本放这里，编译时会打进 APK，首次启动同步到本地列表。

**仓库不包含任何脚本文件**，它们来自玩家社区，版权归各自作者。想要内置就自己
往这个目录放 `.js` 文件；不放也能正常编译，装好后在软件里手动导入即可。

## 命名与默认状态

同步逻辑在 `data/PresetScripts.kt`：

- 默认启用的脚本写在 `DEFAULT_ENABLED` 里，其余默认关闭
- `LOCKED` 里的脚本不允许禁用或删除，用于修复类的常驻脚本
- 文件名带 `00-` 前缀会排在列表最前

## 同步机制

`assetStamp()` 拿目录里所有脚本的「文件名 + 大小」算一个短哈希存起来。
增删脚本或改动内容都会让哈希变化，老用户升级后自动同步：新增的补进来、
内容变了的更新、包里删掉的清除。用户自己导入的脚本不受影响。

所以更新内置脚本只需替换文件重新出包，不用写任何迁移代码。

## 编写要点

WebView 环境和油猴不完全一样，注意两点：

- `100vh` 在这里会算成 `0px`（`useWideViewPort` 导致），项目里有 `VH_FIX`
  自动把 `vh` 换成像素值，但动态生成的内联样式可能盖不到，建议直接用 `px`
- 需要 `GM_*` API 的脚本可以用，项目提供了 `GM_SHIM` 兼容层，
  其中 `GM_xmlhttpRequest` 转由原生转发，可跨域
